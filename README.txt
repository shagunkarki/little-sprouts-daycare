QUICKEST PHONE TEST
1. Upload this whole folder to any static host such as Netlify, Vercel, GitHub Pages, or another static website host.
2. Open the resulting HTTPS link in Safari or Chrome on your phone.
3. Use the 3-line menu in the upper-left to access all 8 sections.
4. On iPhone, use Share > Add to Home Screen if you want it to behave more like an app.
5. On Android Chrome, use the browser menu > Add to Home screen / Install app.

IMPORTANT
The app is frontend-only and uses browser localStorage. Data persists in that browser on that device, but it is not synced to a backend or across devices.
